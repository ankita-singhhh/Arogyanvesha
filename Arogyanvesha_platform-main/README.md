## 🌿 Arogyanvesha – AI-Powered Ayurveda Healthcare Platform

Arogyanvesha is an AI-powered wellness platform that combines the principles of Ayurveda with modern AI to deliver personalized healthcare recommendations. The platform helps users understand their body constitution (Prakriti), receive AI-assisted wellness guidance, discover Ayurvedic herbs, follow yoga routines, and track their health journey through an intuitive and responsive interface.

### ✨ Features
- 🧬 Personalized Prakriti Assessment
- 🤖 AI Health Assistant
- 🧘 Yoga & Lifestyle Recommendations
- 🌿 Ayurvedic Herb Suggestions
- 📊 Wellness Tracking Dashboard
- 🔐 Secure Authentication
- 📱 Responsive & Accessible UI
- ⚡ Real-time AI-powered Health Guidance

### 🛠 Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- SWR
- React Hook Form
- NextAuth.js
- RAG (Retrieval-Augmented Generation)

### 🚀 Highlights
- Built with a scalable and modular architecture.
- Modern UI using reusable components and smooth animations.
- AI integration using RAG for conversational healthcare assistance.
- Optimized for performance, accessibility, and responsive design.
